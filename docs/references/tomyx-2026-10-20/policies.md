## 0-01 · 01. 공통 동작 : 입력·로그인·복귀·오류.pdf

```text
00-A · 공통 동작 / 입력·로그인·복귀·오류
구현 기준 v1 · 2026.10.20 · 확정 UI 59개 대응
AUTH · 접근 권한
게스트 허용: 시뮬레이션, 피드·공개 이야기 읽기, 공유, 브라우저 단위 숨김. 로그인 필요: 글쓰기·공감·신고·차단·MY·알림·설정. 글쓰기→08.02, 공감·신고·차단→08.03, MY→08.07, 알림→05.03. 설정 직접 접근→08.01. 서버도 동일 권한 검
사.
RETURN · 로그인 복귀
로그인 진입 전 originRoute, postId, authorId, action, desiredReaction, scroll, draftKey를 1회성 의도로 저장한다. 필수 동의 완료 후 권한·대상 상태를 재조회한다. 글쓰기는 초안 분기, 공감은 원래 목표 상태 1회 적용, 신고는 사유 화면, 차단
은 확인 화면, MY/알림은 재조회. 취소·실패에서는 액션 실행 없음. 공개 확인·신고·차단 등 확정 동작은 재인증만으로 자동 제출하지 않는다.
INPUT · 본문
본문만 입력. trim 결과 비어 있지 않고 원문 1–1,000개의 사용자 인식 문자이면 유효. 공백·줄바꿈은 본문에 보존. 한글 조합 완료 시 검증, 초과 붙여넣기·입력은 1,000자까지만 반영하고 안내. 카운터·서버 검증에 동일한 문자 분할 함수를 사용한다.
SUMMARY · 자동 요약
본문 앞뒤 공백 제거 → 줄바꿈·연속 공백을 한 칸으로 → 앞 20개의 사용자 인식 문자 발췌 → 잔여 내용 있으면 … 추가. 본문은 변경하지 않는다. 미리보기는 한 줄 말줄임. 피드·MY 제목은 이 요약을 같은 값으로 사용하고 해당 UI의 행 제한·폭을 따른
다. 별도 제목 입력 없음.
DRAFT · 초안·진행
초안은 로그인 계정별·동일 브라우저에 저장. 입력 변경 후 500ms 내 저장하고 이탈 전 저장 성공 확인. 자동 만료·기기 간 동기화 없음. 삭제는 새로 시작 명시 확인, 등록 성공, 로그아웃·탈퇴 때만. 로그아웃에 미게시 초안이 있으면 삭제 안내·확인 필
수. 저장 실패는 본문 유지·재시도. 시뮬레이션 진행은 브라우저에 별도 보관.
REQUEST · 로딩·잠금·실패
최초 조회: 내용 영역 로딩, 0건 문구 미표시. 추가 조회: 기존 목록+말미 진행 표시. 읽기·변경 요청 15초 무응답은 오류/결과 불명으로 전환. 동일 액션 중복 탭 잠금. 조회는 사용자가 재시도. 변경 요청은 자동 반복하지 않고 시도 ID로 결과를 확인한다.
등록·탈퇴의 응답 유실은 확정 실패와 구분.
ERROR · 공통 분기
UNAUTHENTICATED→의도·입력 보존 후 적절한 로그인. FORBIDDEN/NOT_FOUND/UNAVAILABLE→07.09(본문 미표시). VALIDATION→해당 입력·사유 아래 오류. NETWORK/TIMEOUT/SERVER_ERROR→현재 화면 오류·재시도.
RATE_LIMITED→서버 retryAfter 동안 비활성·남은 시간 안내. 사용자에게 내부 오류 원문·개인정보 노출 금지.
NAV · 뒤로·모달
뒤로는 진입 화면·탭·대상·스크롤 복원. 이전 이력이 없으면 04.01. 키보드 표시 중 1회 뒤로는 키보드만 닫기. 시트 바깥 탭·뒤로는 닫기, 처리 중에는 닫기 잠금(로그인 취소만 예외). 시트 배경은 터치·보조 읽기 비활성. 닫을 때 호출한 버튼으로 포커
스 복원.
SCROLL · 피드
아래로 80 CSS px 초과 이동하면 벨·소리·스토리·MY 숨김, +만 고정. 위로 8px 이상 또는 최상단이면 복원. +는 전후 좌표·크기 동일. 터치 영역 최소 44×44. 피드 이미지·본문은 스크롤하고 고정 컨트롤은 스크롤 밖 배치.
SOUND · 소리
기본 음소거. 사용자의 직접 탭에서만 재생을 요청하고 앱 숨김·다른 화면에서 일시정지. 같은 브라우저의 소리 선택은 유지. 재생 거부·자산 미설정·실패는 음소거로 표시하며 피드 이용을 막지 않는다. MY의 소리 컨트롤도 같은 상태를 사용한다.
VISUAL · 반응형·접근성
375×812는 기준 뷰포트. 화면 폭에 맞게 콘텐츠·CTA 확장, 좌우 기본 여백 24px, 상·하단 safe area 반영. 긴 글·큰 글자에서 본문 스크롤, CTA 접근 보장. 오류·선택·비활성은 색 외 텍스트/접근성 상태로 전달. 개발 주석은 서비스 UI에 포함하지 않
```
