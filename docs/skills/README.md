# 프로젝트 스킬

이 프로젝트에서 사용하는 공통 스킬의 목록입니다. 스킬 원본은 `docs/skills/<이름>/SKILL.md`에서 관리하고, 특정 에이전트의 대화 이력에 절차를 보관하지 않습니다.

## 스킬 목록

| 스킬 | 역할 | 실행 시점 |
| --- | --- | --- |
| [documentation-review](documentation-review/SKILL.md) | 변경 내용과 정책·스펙·운영 문서의 일치 여부를 검토하고 누락을 보완 | 에이전트가 매 커밋·빌드를 실행하기 전, 문서 리뷰 요청 시 |

개인 환경에 설치된 범용 스킬은 프로젝트 공통 스킬과 구분합니다. 개발 절차에 필요한 스킬을 추가하면 원본 경로, 역할, 실행 시점을 이 목록에 등록합니다.

## 자동 실행 방식

`AGENTS.md`가 커밋·빌드 전 `documentation-review`를 필수로 읽고 수행하도록 지정합니다. Claude Code도 `CLAUDE.md`에서 같은 지침을 읽습니다. 현재 세션에서 스킬 목록에 보이지 않더라도 원본 파일을 직접 읽어 실행합니다.

Codex의 `.agents/skills/documentation-review`와 Claude Code의 `.claude/skills/documentation-review`는 같은 원본을 가리키는 상대 심볼릭 링크입니다. 스킬 본문을 복제하지 않습니다. 새 PC에서도 저장소와 링크를 함께 가져옵니다. 링크가 지원되지 않는 환경에서는 `AGENTS.md`에 적힌 원본 경로를 직접 읽습니다.

이는 에이전트 지침에 따른 실행입니다. 사람이 터미널에서 직접 실행한 Git·빌드 명령이나 CI를 가로채는 훅은 설치하지 않았습니다. 스킬 호출도 에이전트의 지침 준수에 의존하므로 OS 수준의 실행 차단으로 보지 않습니다.

## 추가와 변경

- 새 스킬에는 이름, 설명, 실행 조건과 완료 기준을 작성합니다.
- 공통 지침에는 필수 실행 시점과 원본 경로만 남기고 상세 절차는 스킬에서 관리합니다.
- 기존 정책이나 운영 기준은 참조하고 복제하지 않습니다.
- 스킬 변경 시 목록, 에이전트 연결 경로와 실제 동작을 함께 확인합니다.
